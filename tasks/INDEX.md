# Published work queue

任务状态只以 [STATUS.md](../STATUS.md) 为准。每轮一个 PR，未过审不得进入下一轮。

| 阶段 | 可见交付 | 审计闸门 |
|---|---|---|
| [S00](S00_BOOTSTRAP.md) | 可复现工程、最小可启动界面、环境与构建记录 | 真实 iOS 编译/模拟器证据；没有 Mac 就报告环境阻塞 |
| [S01](S01_IMPORT.md) | 选照片、权限分支、页序预览、私有源映射 | 有限/拒绝权限和缺日期不漏页、不虚报 |
| [S02](S02_ARCHIVE.md) | 图片/OCR/MD/PDF/manifest/ZIP 完整产物 | 真文件结构、页数、图像、hash、ZIP 均可验证；无图库清理 |
| [S03](S03_EXPORT_CLEANUP.md) | 完整导出、恢复、用户确认后精确清理 | 导出取消/损坏/权限变化不触发清理，独立本地留存 |
| [S04](S04_DEVICE_QA.md) | 经真机验证的 MVP | 100–200页、低空间、中断、电脑解压、数据安全；P0/P1为零 |
| [S05](S05_RELEASE.md) | TestFlight → 送审 → 商店可下载 | 分发版实测、签名/元数据/隐私/审核状态真实 |

不把“后续优化”无限堆入 MVP。裁切、去重和最佳帧在所有阶段都不属于范围。

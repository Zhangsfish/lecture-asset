# Owner-only account setup for S00 TestFlight

Do these steps in your own signed-in Apple and GitHub browser. Send back only **done / pending / unavailable** for each section. Do not send a `.p8` file, its text, API identifiers, Apple Account details, certificates, screenshots containing account data, or GitHub secret values to chat.

1. **Apple membership and agreements.** In [Apple Developer Account](https://developer.apple.com/account/), check that Program membership is Active. In [App Store Connect](https://appstoreconnect.apple.com/), accept any agreement shown in Business. Apple requires the latest agreement before creating an app record.
2. **Identifier and app record.** In Developer Account → Certificates, Identifiers & Profiles → Identifiers, register an explicit App ID with bundle ID `com.zhangsfish.lectureasset` if it does not already exist. In App Store Connect → Apps → **+** → New App, choose iOS, that Bundle ID, an available app name (prefer `Lecture Asset`), a primary language, and a stable SKU such as `lecture-asset-ios`. Do not submit the app for public review.
3. **Team API key.** In App Store Connect → Users and Access → Integrations → App Store Connect API, the Account Holder selects Request Access and agrees to its terms if needed. Apple reviews this request. Once approved, choose **Team Keys** → Generate API Key, name it for S00 TestFlight CI, and assign the **Admin** role for this first automatic signing attempt. This role has broad access across the account's apps; keep the key private and revoke it after S00 TestFlight work if no further build is needed. Download the `.p8` file once. An Individual Key is unsuitable for the provisioning operations used here.
4. **GitHub Actions Secrets.** In this repository → Settings → Secrets and variables → Actions → New repository secret, add exactly these four names. Obtain each value from your Apple pages or downloaded private key and enter it directly into GitHub's secret field: `S00_APPLE_TEAM_ID`, `S00_ASC_API_KEY_ID`, `S00_ASC_API_ISSUER_ID`, `S00_ASC_API_KEY_P8` (the full downloaded `.p8` text, including BEGIN/END lines). Store all four as **Secrets**, not Variables. Keep the `.p8` file in your own secure storage.

After all four sections are complete, tell Codex only that the identifier, app record, Team Key, and four GitHub Secrets are ready. Codex can then explicitly trigger the upload and inspect only redacted CI status. A successful upload still needs Apple's processing step before the build is available in TestFlight.

Sources: [Apple App ID registration](https://developer.apple.com/help/account/identifiers/register-an-app-id), [new app record](https://developer.apple.com/help/app-store-connect/create-an-app-record/add-a-new-app), [API access and Team Keys](https://developer.apple.com/help/app-store-connect/get-started/app-store-connect-api/), [Team versus Individual key capabilities](https://developer.apple.com/documentation/AppStoreConnectAPI/creating-api-keys-for-app-store-connect-api), [GitHub Actions repository secrets](https://docs.github.com/en/actions/how-tos/write-workflows/choose-what-workflows-do/use-secrets).
